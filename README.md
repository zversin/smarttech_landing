# Лендинг на GitHub Pages

## Видеонаблюдение на этаж

Новая страница: `/videonablyudenie-dlya-etazha/`. GitHub Pages перенаправляет адрес без завершающего `/` на каталог с `index.html`.

Проект остаётся статическим HTML/CSS/JavaScript. Для сборки новой страницы нужен Node.js 18+; npm-зависимостей нет. GitHub Pages публикует готовый HTML из репозитория, поэтому в коммит нужно включать результат сборки.

```bash
npm run build
npm run lint
python3 -m http.server 4173
```

- **Цена:** `FLOOR_CCTV_PRICE` в `videonablyudenie-dlya-etazha/config.mjs`. Менять только здесь, затем выполнить `npm run build`. Hero, сравнение, калькулятор, WhatsApp и SEO используют эту настройку. HTML содержит сгенерированные значения и читается без JavaScript.
- **Контент:** `templates/cctv-floor.html`. Генерируемый `videonablyudenie-dlya-etazha/index.html` не редактировать вручную.
- **Общие элементы:** сборка берёт navbar/footer из главного `index.html`; кнопки, шрифты, цвета и FAQ используют общий `style.css`. Навигация обеих страниц использует `navigation.js`. Новая страница русскоязычная; главный сайт сохраняет RU/KZ/EN.
- **Фото:** `public/images/cctv-floor/README.md` и `videonablyudenie-dlya-etazha/photos.mjs` описывают имена и места размещения. До добавления файлов отображаются заглушки без 404.
- **WhatsApp:** `WHATSAPP_NUMBER` в конфиге, сейчас тот же номер, что на главной: `77087262237`. CTA содержит описание услуги и цену. Форма валидирует данные и открывает подготовленное сообщение с именем, телефоном, адресом, подъездом, этажом и количеством квартир. Пользователь отправляет его в WhatsApp самостоятельно. Backend и подтверждения доставки нет; интерфейс не сообщает об отправленной заявке.
- **Аналитика:** в исходном проекте отсутствует. Новых счётчиков нет. Если подключён `gtag` или `dataLayer`, используются события `cctv_floor_whatsapp_click`, `cctv_floor_form_open`, `cctv_floor_form_submit`, `cctv_floor_calculator_change`. `form_submit` означает передачу сообщения в WhatsApp (`channel: whatsapp_handoff`), не доставку. Персональные данные в события не включаются.
- **Lint:** без внешних библиотек проверяет синтаксис JavaScript, актуальность сборки, H1, уникальность id, якоря, локальные ресурсы, согласованность цен и границы калькулятора.

Существующий хостинг GitHub Pages и `CNAME` не меняются.

## 📦 Деплой на GitHub Pages

### Шаг 1: Создайте репозиторий на GitHub

1. Зайдите на [github.com](https://github.com)
2. Нажмите "New repository"
3. Назовите репозиторий, например: `my-landing-page`
4. Выберите "Public"
5. Нажмите "Create repository"

### Шаг 2: Загрузите файлы в репозиторий

Откройте терминал в папке с проектом и выполните:

```bash
git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin https://github.com/ВАШ_ЮЗЕРНЕЙМ/my-landing-page.git
git push -u origin main
```

### Шаг 3: Настройте GitHub Pages

1. Перейдите в настройки репозитория (Settings)
2. Найдите раздел "Pages" в левом меню
3. В разделе "Source" выберите:
   - Branch: `main`
   - Folder: `/ (root)`
4. Нажмите "Save"

### Шаг 4: Готово!

Ваш сайт будет доступен по адресу:
```
https://ВАШ_ЮЗЕРНЕЙМ.github.io/my-landing-page/
```

Обычно деплой занимает 1-5 минут.

## ⚙️ Настройка

### Изменение контента

Отредактируйте файл `index.html`:
- Замените "MyBrand" на название вашего бренда
- Измените тексты в секциях
- Добавьте свои ссылки на соцсети

### Изменение цветов

В файле `style.css` измените переменные в `:root`:
```css
:root {
    --primary-color: #6366f1;  /* Основной цвет */
    --secondary-color: #8b5cf6; /* Дополнительный цвет */
    --dark-color: #1f2937;      /* Темный цвет */
}
```

### Добавление своих изображений

Замените `.image-placeholder` в `index.html` на:
```html
<img src="your-image.jpg" alt="Описание">
```
