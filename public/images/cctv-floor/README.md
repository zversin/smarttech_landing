# Изображения лендинга для этажа

Каталожные фотографии и официальный скриншот приложения уже подключены. Источники, модели и контрольные суммы — в [SOURCES.md](SOURCES.md).

| Файл | Назначение |
| --- | --- |
| `hilook-camera.jpg` | Камера HiLook THC-T150-P: первый экран и галерея |
| `hilook-recorder.jpg` | Регистратор HiLook DVR-204Q-M1: первый экран и галерея |
| `hdd-1tb.webp` | Пример HDD 1 ТБ: первый экран и галерея |
| `hilook-app.jpg` | Скриншот HiLook для iOS: галерея |

При замене обновите имя, alt и реальные размеры в `videonablyudenie-dlya-etazha/photos.mjs`, затем выполните `npm run build`. Подписи и ссылки на источники находятся в `templates/cctv-floor.html`. Не обозначайте каталожные фотографии или скриншоты разработчика как собственные работы SmartTech. Реальные фотографии установок можно добавить отдельными карточками после получения материалов заказчика.

`og.png` — карточка ссылки, созданная встроенным ImageGen. Она не изображает оборудование или монтаж; точный промпт сохранён в `og-prompt.txt`.
