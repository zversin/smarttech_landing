# Фотографии лендинга для этажа

Положите реальные фото в эту папку под следующими именами и выполните `npm run build`:

| Файл | Место на странице |
| --- | --- |
| `hilook-camera.jpg` | Камера в hero |
| `hilook-recorder.jpg` | Регистратор в hero |
| `hdd-1tb.jpg` | HDD в hero |
| `installation-elevator.jpg` | Галерея: лифтовой холл |
| `installation-corridor.jpg` | Галерея: коридор |
| `installation-recorder.jpg` | Галерея: установленный регистратор |
| `mobile-app.jpg` | Галерея: скриншот приложения |

Рекомендуется 1200 × 900 px для фото, для скриншота можно сохранить вертикальные пропорции. Изображения показываются целиком через `object-fit: contain`. Для PNG/WebP поменяйте имя файла в `videonablyudenie-dlya-etazha/photos.mjs`.

Отсутствующие файлы не запрашиваются: сборка оставляет подписанные HTML/CSS-заглушки. После добавления фото обновите подписи «скоро добавим» в `templates/cctv-floor.html` при необходимости. Не выдавайте схему интерфейса за реальный скриншот приложения.

`og.png` — готовая карточка ссылки, созданная встроенным ImageGen. В ней нет цены, поэтому изменение стоимости не требует замены картинки. Точный промпт сохранён в `og-prompt.txt`.
